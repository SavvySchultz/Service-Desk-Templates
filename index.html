How the templates could look with Hardware and Software split into their own categories. This is a suggestion only; nothing has changed in the app.

Why split them

Only one of the current subgroups (“Problem with computer program”) is really software related, so maybe we could create separate Hardware Issues and Software Issues categories. That would keep Hardware Issues focused on printers, equipment, and Mac/PC problems, while giving software related requests their own place. I think it would make categories more clear for users, and it would also give us a good spot for things like adding SharePoint site issues and conferencing issues if we decide to add them.
